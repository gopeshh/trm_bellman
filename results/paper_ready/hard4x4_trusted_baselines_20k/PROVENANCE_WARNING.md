# Historical records with incompatible provenance

These files are retained for audit history, not as a method comparison. The
UPI-TRM row was evaluated in-sample. The SB3 rows used a different held-out
pool, and no common ordered-pool hash exists. The stored gap interval is invalid
for inference and must not be cited.

Fresh aggregation uses `scripts/aggregate_hard4x4_trusted_baselines.py`, which
rejects missing or mismatched pool hashes.
