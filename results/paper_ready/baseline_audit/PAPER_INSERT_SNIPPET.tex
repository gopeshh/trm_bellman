\subsection{Baseline Implementation Audit}
\label{app:baseline-audit}

To probe sensitivity to baseline implementation, we ran a supplementary
audit on the hard no-mask 4$\times$4 Sudoku benchmark at a
320{,}000-environment-interaction budget (larger than the main paper's
baseline comparisons). PPO and A2C were rerun with independently
implemented CleanRL-style training loops. DQN was rerun through a
benchmark-harness wrapper around the in-house \texttt{DQNTrainer},
because the Sudoku-specific CleanRL DQN port remained unresolved in the
audited checkout. All runs used the same hard 4$\times$4 no-mask dataset,
feasibility checker, reward shaping, success criterion, and 10-seed
protocol. PPO and A2C used the standard plan-policy evaluator; DQN used
greedy $\arg\max Q$ evaluation.

All three audited baselines remained at 0.0\% success across all seeds,
reinforcing that standard RL baselines do not solve this benchmark.
The DQN audit row should not be interpreted as independent evidence,
since it uses the in-house trainer through a benchmark wrapper rather
than an independent CleanRL Sudoku DQN implementation. An independent
Sudoku DQN ($n{=}5$) audit remained unresolved in the audited checkout
and is therefore reported as unavailable rather than omitted.

Note that this audit uses a 320k-interaction budget, which differs from
the main paper's baseline comparisons. Direct numerical comparison
between these audit rows and the main table rows is not appropriate
without accounting for the budget difference.
