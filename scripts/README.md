# RL Ablation Scripts

This directory contains scripts for running systematic ablation studies on RL training hyperparameters.

## Contents

- **`sweep_rl.sh`**: Main sweep script that runs experiments across hyperparameter combinations
- **`parse_sweep_results.py`**: Analysis script to parse results and generate summaries

## Quick Start

### Run a Full Sweep

```bash
# Make script executable
chmod +x scripts/sweep_rl.sh

# Run sweep (warning: this will run many experiments!)
./scripts/sweep_rl.sh
```

The sweep will:
- Enumerate all combinations of hyperparameters
- Run training for each configuration
- Save logs to `runs/sweep_<timestamp>/`
- Generate CSV results: `runs/sweep_<timestamp>/sweep_results.csv`

### Hyperparameter Ranges

Default ranges (can be edited in `sweep_rl.sh`):

| Parameter | Values |
|-----------|--------|
| `rl.K` | {1, 3, 5} |
| `rl.n_inner` | {2, 4, 6, 8} |
| `rl.spectral.target_prod` | {0.90, 0.95, 0.99} |
| `rl.ppo_clip` | {0.1, 0.2, 0.3} |

**Total experiments**: 3 × 4 × 3 × 3 = **108 runs**

### Analyze Results

```bash
# Parse and analyze sweep results
python scripts/parse_sweep_results.py runs/sweep_<timestamp>

# Rank by specific metric
python scripts/parse_sweep_results.py runs/sweep_<timestamp> --metric final_loss --top-k 10
```

## Output Format

### CSV Results (`sweep_results.csv`)

Columns:
- `run_id`: Sequential run identifier
- `K`: Number of rollout steps
- `n_inner`: Inner recursion depth
- `spectral_target_prod`: Spectral norm target
- `ppo_clip`: PPO clipping parameter
- `status`: `success` or `failed`
- `final_loss`: Final training loss
- `best_accuracy`: Best accuracy achieved
- `steps_to_solution`: Total training steps
- `runtime_sec`: Runtime in seconds

### JSON Summary (`sweep_summary.json`)

Generated by `parse_sweep_results.py`:
- Overall statistics (success rate, mean loss, etc.)
- Top-k best runs by metric
- Hyperparameter effect analysis (mean loss per parameter value)

## Customization

### Modify Hyperparameter Ranges

Edit `sweep_rl.sh`:

```bash
# Example: Test more K values
K_VALUES=(1 2 3 4 5)

# Example: Add custom PPO clip values
PPO_CLIP_VALUES=(0.05 0.1 0.15 0.2 0.25 0.3)
```

### Change Base Configuration

Edit the `BASE_CMD` in `sweep_rl.sh`:

```bash
BASE_CMD="python train_rl.py \
  arch=trm \
  data_paths=[data/sudoku-extreme-1k-aug-1000] \
  rl.enabled=True \
  arch.L_layers=2 \
  arch.H_cycles=3 \
  arch.L_cycles=4 \
  epochs=10"  # <-- Increase epochs
```

### Subset Sweep

To run a quick test with fewer combinations:

```bash
# Edit sweep_rl.sh
K_VALUES=(3)           # Only test K=3
N_INNER_VALUES=(4 6)   # Test 2 values
SPECTRAL_TARGET_VALUES=(0.95)  # Only default
PPO_CLIP_VALUES=(0.2)  # Only default

# This gives: 1 × 2 × 1 × 1 = 2 runs
```

## Parallel Execution

To run multiple experiments in parallel (be careful with GPU memory):

```bash
# Use GNU parallel (install: brew install parallel)
# Modify sweep_rl.sh to export function, then:
export -f run_single_experiment
parallel -j 4 run_single_experiment ::: configs/*.yaml
```

Or use a cluster scheduler like SLURM:

```bash
sbatch --array=0-107 scripts/sweep_rl.slurm
```

## Example Workflow

```bash
# 1. Run a quick subset sweep
./scripts/sweep_rl.sh

# 2. Analyze results
python scripts/parse_sweep_results.py runs/sweep_20250110_143022

# 3. View CSV
cat runs/sweep_20250110_143022/sweep_results.csv | column -t -s ','

# 4. Check JSON summary
cat runs/sweep_20250110_143022/sweep_summary.json

# 5. Inspect specific run logs
cat runs/sweep_20250110_143022/rl_K3_n6_sn0.95_ppo0.2/training.log
```

## Notes

- Each run saves logs to a separate subdirectory
- Failed runs are marked in the CSV but don't stop the sweep
- The sweep continues from where it left off if interrupted (manual restart required)
- Logs are never overwritten (timestamped directories)

## Tips for Large Sweeps

1. **Start small**: Test with a subset first
2. **Monitor GPU**: Watch `nvidia-smi` to avoid OOM
3. **Use checkpoints**: Runs save checkpoints for recovery
4. **Parallel safely**: Don't exceed GPU capacity
5. **Archive results**: Copy `runs/` to external storage regularly
